# 개인 APK의 로컬 API 키

2026-09-18 사용자 결정: 키를 Git에 넣지 않고 개발 PC의 로컬 파일에서 읽어 개인 APK에 포함한다. 모바일 키 입력과 Keystore 저장은 현재 개발 범위에서 제외한다.

## 설정

프로젝트 루트에서 `npm run keys:init`을 실행하면 빈 `.env.example`을 `.env.local`로 복사한다. 기존 파일은 읽거나 덮어쓰지 않는다. 사용자가 편집기에서 `.env.local`의 세 항목을 직접 채운다.

| 항목 | 값 |
| --- | --- |
| NESTQUEST_PUBLIC_DATA_KEY | 공공데이터 일반 인증키 Decoding |
| NESTQUEST_KAKAO_REST_KEY | 카카오 REST API 키 |
| NESTQUEST_KAKAO_JAVASCRIPT_KEY | 카카오 지도 JavaScript 키 |

실제 값은 채팅·소스·스크린샷에 보내지 않는다. Vite env 문법상 `$`는 `\$`로 이스케이프해야 한다. 상세 동작: https://vite.dev/guide/env-and-mode

`npm run keys:check`은 개발 설정, `npm run keys:check -- production`은 빌드 설정의 등록/미등록만 출력한다. 키·일부 문자·해시를 출력하지 않고 외부 API를 호출하지 않는다. 등록됨은 인증 성공을 보장하지 않는다.

키 수정 후 개발 서버를 다시 시작한다. APK에는 빌드 시점 값이 포함되므로 키를 변경/재발급하면 다시 빌드하고 설치한다. 다른 개인은 자신의 키로 같은 절차를 따른다. 일부 키 없이도 빌드되며 해당 온라인 조회만 제한된다.

## 빌드와 공유

- 기존 `npm run build`, `npm run android:apk`, `npm run android:release` 흐름이 로컬 설정을 자동 반영한다. 실제 APK 빌드/설치는 사용자 요청대로 기능 개발 후 진행한다.
- 파일 자체를 APK assets에 복사하는 대신 필요한 세 값만 번들에 주입한다. 서명 비밀번호·철도 자료 수집용 키 등은 이 주입 대상이 아니다.
- `.env`, `.env.*`는 Git에서 제외하고 빈 `.env.example`만 공유한다. `dist/`, Android 복사 assets, APK/AAB, 서명 keystore도 제외한다. 과거에 이미 추적한 파일은 ignore 규칙만으로 추적 해제되지 않는다. 현재 작업 폴더에는 Git 저장소가 아직 없다.
- 임장 백업에는 키를 넣지 않는다. 키가 있는 APK/웹 빌드는 개인용 결과물이며 공개 웹사이트나 공개 릴리스에 올리지 않는다. 소스만 공유하고 다른 사용자는 자신의 키로 빌드한다.
- `.env.local`에 입력한 값은 **웹 빌드에도 포함**된다. APK를 포함한 결과물을 가진 사람은 분석으로 키를 추출할 수 있다. `.gitignore` 또는 번들 압축은 키 암호화가 아니다.

## 개발 도구와의 경계

- `.gitignore`는 개발 도구의 파일 접근을 막지 않는다. 키를 제가 절대 볼 수 없다는 보장은 하지 않는다.
- `AGENTS.md`에 실제 키 파일·키가 포함된 빌드 산출물·환경변수 내용을 읽거나 출력하지 않는 작업 규칙을 두었다. 이는 접근권한 차단이 아닌 작업 규칙이다.
- 정상 dev/build 프로세스와 등록 여부만 확인하는 keys:check 명령은 설정을 소비할 수 있다. 테스트용 빌드 설정은 실제 키를 주입하지 않고 빈 값으로 대체한다.
- 개발은 소스와 합성 응답으로 진행하고 연결 시험에서는 성공/실패 코드 등 키 없는 진단만 사용한다. 제공자가 URL 매개변수로 키를 요구할 수 있으므로 네트워크 로그나 요청 URL을 그대로 공유하지 않는다.

## 현재 상태

로컬 파일→개발/빌드 설정 주입, 읽기 전용 등록 상태 UI, Git 제외, 키 없는 단위 테스트를 구현했다. 공공·카카오 주소·카카오 통근 인증 표본은 확인했다. Android APK 실행은 미검증이다.
