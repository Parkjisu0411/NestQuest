# 개인 로컬 사용

## APK 확정 · 2026-09-18

최종 모바일 형태는 스토어 없이 직접 설치하는 Android APK로 확정했다. 아래의 APK 미정 표기는 이전 이력이다. Capacitor Android 프로젝트, 네이티브 백업 저장 위치 선택, 앱 뒤로가기, 사진 원본 뷰어 및 빌드/서명 설정을 추가했다. 현재 PC에 JDK 21 및 Android SDK가 없어 네이티브 컴파일과 APK 생성은 아직 완료하지 못했다. 최신 실행 방법과 남은 작업은 [ANDROID.md](ANDROID.md)를 따른다.

2026-09-18 사용자 결정: 공개 웹 배포를 목표로 하지 않는다. 본인 모바일에서 사용하며, 다른 사용자는 Git 저장소를 내려받아 직접 설치하는 방식으로 공유한다. APK는 안드로이드 설치 파일이며 스토어 등록 없이 배포·설치할 수 있다. 최종 형태는 개인 APK로 확정했다.

## PC에서 소스로 실행

저장소 폴더에서 설치된 Node.js/npm을 사용한다. 프로젝트의 Vite 엔진 요구사항에 맞는 Node 버전을 사용한다.

```sh
npm ci
npm run local
```

주소는 `http://127.0.0.1:4173`이다. `npm run local`은 빌드 후 로컬 서버를 실행한다. 빌드가 있으면 `npm start`로 다시 실행할 수 있다. 서버는 PC의 loopback에만 연결하며 다른 기기에 공개하지 않는다. Node 내장 모듈로 실행하므로 별도 호스팅 계정이나 전역 서버 패키지가 필요 없다. 다른 포트가 꼭 필요하면 `NESTQUEST_PORT` 환경변수를 설정한다.

개발은 `npm run dev`, 검증은 `npm test`, `npm run lint`, `npm run build`로 진행한다. 개발 모드에는 서비스 워커를 등록하지 않는다.

## 기록의 위치

기록·사진·초안은 브라우저의 IndexedDB에 저장된다. 주소의 호스트와 포트, 브라우저 프로필이 다르면 별도 저장소다. 개발 주소에서 로컬 실행 주소로 옮길 때는 사진 포함 `.nestquest` 백업을 내려받고 새 주소 첫 화면의 `백업으로 시작`에서 복원한다. 서버가 기록을 수집하거나 계정 간 동기화하지 않는다.

JSON은 기록과 사진 메타데이터만 포함한다. `.nestquest`는 기록과 참조된 사진 원본을 포함하며 현재 최대 200MiB다. 작성 중 임장 초안은 백업에 포함하지 않는다. 기기를 바꾸기 전 임장을 완료 저장하고 백업한다. 완료 방문 수정/독립 평가 편집은 자동 초안이 없으며 화면 이탈 확인으로 보호한다.

## 오프라인과 업데이트

실제 빌드를 한 번 온라인으로 열어 `오프라인 실행 준비됨`을 확인하면 앱 화면/코드/아이콘이 캐시된다. 저장된 기록·원본 사진은 IndexedDB에서 읽고, 오프라인에서도 임장 작성·수정·저장할 수 있다. 앱 데이터/브라우저 저장소를 삭제하거나 브라우저가 데이터를 회수하면 오프라인 사용 및 기록이 사라질 수 있으므로 백업은 별도 파일로 보관한다. 설정에서 사용량과 지속 저장 상태를 확인할 수 있다. 지속 저장 허용 여부는 브라우저가 결정한다.

새 빌드를 서버에서 제공하면 서비스 워커가 새 파일을 준비한다. 앱을 사용 중일 때 강제로 새로고침하지 않는다. `새 버전이 준비됐습니다`가 나오면 입력을 저장한 뒤 같은 주소의 창을 모두 닫고 다시 연다. 앱 캐시 교체는 사용자 IndexedDB를 지우지 않는다. `skipWaiting`에 의한 편집 중 코드 교체는 사용하지 않는다.

홈 화면 설치 버튼은 설치를 지원하는 환경에서만 보인다. 보이지 않으면 브라우저 메뉴를 확인한다. Android의 앱 설치/PWA 지원과 실제 카메라·파일 선택은 실기기 확인이 필요하다. PC의 `127.0.0.1`은 휴대폰에서 접속하는 주소가 아니며, PC 서버를 켰다고 휴대폰 앱이 설치되는 것은 아니다.

## 모바일 최종 형태

웹 화면을 Android 앱에 포함하고 네이티브 뒤로가기·사진/파일 선택·백업 내보내기 코드와 서명 설정을 연결했다. 브라우저 다운로드 코드가 Android WebView에서 동일하게 작동한다고 가정하지 않는다. Android 빌드 환경 및 APK 생성은 아직 수행하지 않았다. 앱 ID와 서명 키를 유지한 업데이트를 사용해야 하며, 삭제 후 재설치는 백업 없이는 기록을 잃을 수 있다.

실제 아파트/통근 API는 웹에서 검증했다. APK/폴드 실기기 검증은 별도 단계다. 예시 모드는 실제 조사 자료와 구별해서 사용한다.
