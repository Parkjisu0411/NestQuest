# 실제 연동 및 통합 검증 · 2026-09-21

아래 날짜별 기록은 당시 검증 결과다. ODsay·차단 UI·구형 지도에 관한 과거 기록은 현재 구현을 뜻하지 않는다. 현재 구조는 [ROADMAP.md](ROADMAP.md)를 따른다.

## 실제 응답

- 공공데이터·Kakao REST·ODsay 인증 성공. 키·인증 URL·원문은 문서에 기록하지 않는다.
- 서울 25구 단지 3,404개, 전체 35페이지 및 ID 중복 검사 성공.
- 25개 구에서 단지 1개씩 기본·상세·좌표와 최근 완료 계약월 거래 응답 확인. 서대문/강북 주소 문제 보완 후 두 구 재검증 성공. 전체 단지 상세/가격 수집 완료라는 뜻은 아니다.
- 기존 영등포구 표본 20개 기본·상세·좌표, 12개월 거래 3,088건과 표본 6개 가격 연결 확인.
- ODsay 공개 위치 표본 정상 경로(20분·3구간) 파싱. 출근시각 예측/최종 통근 보장이 아니며 실행 메모리만 사용.

## 보완과 자동 검증

도로명 실패/모호함은 전체 지번 주소로 재확인하고 인증·한도·네트워크 오류는 즉시 중단한다. 단지 거래 ID 충돌은 해당 단지만 미확인으로 처리한다. 전용면적별 실제 거래 이력, 구버전 거래 연결, 취소 원거래 제외와 같은 반올림 면적 구분을 보완했다.

비교 검색/30개 페이지와 선택 단지 유지, 이웃 셀까지 확인하는 지도 묶음, 초기 설정의 실제 경계/출근역 선택을 적용했다.

**295개 테스트, lint, TypeScript/Vite/오프라인 웹 빌드 통과.** 최대 JS 청크 약 352KB로 기존 크기 경고 해소.

## 브라우저 흐름

사용자 저장소와 분리한 QA 주소 5176/5177에서 확인했다.

- 실제 목록 갱신 후 합성 임장 유지, 실제 좌표/거래 저장과 여의도 출근역 유지.
- 800×900 지도·목록 및 360×740 입력, 묶음 선택과 목록 페이지 동기화.
- 방문 전 최종 후보, 사진 임장 작성·수정·새로고침 후 유지, 두 단지 비교와 거래 이력.
- 초기 실제 여의도역 검색/선택 및 서울 25구 지도.
- 빈 저장소에 합성 사진 백업 최종 복원 후 항목·사진 원본 연결/표시.
- 합성 통합 테스트: 수집→조건→후보→임장/평가→수정→사진 백업 왕복.

## 재검증

일반: npm test / npm run lint / npm run build.
키 존재: npm run keys:check.
실제 API: npm run api:verify 또는 npm run api:verify -- --districts.
특정 구: npm run api:verify -- --districts=11410,11305.

실제 API는 무료 호출량을 쓰며 자동 테스트/빌드가 실행하지 않는다. 이번 전체 구 검사 140회, 주소 보완 후 두 구 검사 51회(목록 수집 포함). 실행별 상한 150회. 임장/사진 저장소를 읽거나 변경하지 않고 개수/성공만 출력한다.

## 실제 자료 전용 전환 · 2026-09-21

예시 단지 fallback과 탐색 화면의 구형 지도 분기를 제거했다. 저장 목록이 없으면 공공 API 목록을 자동 수집하며, 목록에서 단지를 선택하거나 상세를 열면 기본정보·좌표·구별 거래·출근역 통근을 조회한다. 같은 구 거래는 실행 중 재사용한다. 조회 오류는 재시도 안내로 표시하고 예시값으로 대체하지 않는다. 미연결 기존 기록의 ID/임장/평가는 보존하되 허구의 단지 사실은 표시하지 않는다. 지도·역·노선은 최초 설정과 탐색 모두 같은 공식 공개 자료 번들을 사용한다. 실시간 지도 API 호출은 하지 않는다.

서울 전체 상세/통근을 한 번에 일괄 수집하는 방식은 아니다. 미조회 단지는 미확인으로 표시되며 일괄 갱신 화면도 유지한다. 경기 예시 지역 선택은 제거했다.

회귀 테스트 298개 통과. 별도 QA에서 풍납 대동아파트 선택 후 실제 기본정보(93세대), 여의도 46분 통근, 지도 좌표 반영을 확인했다. 유효 거래를 연결하지 못한 가격/면적은 미확인으로 유지했다.

## 카카오 지도 검증 · 2026-09-21

카카오 JavaScript 키 존재 확인 및 등록된 127.0.0.1:4173의 격리 QA 화면에서 실제 SDK·배경 타일·아파트 오버레이 로딩 성공. 합성 아파트 묶음→선택, 목록 선택→위치 이동, 필터 제외, 360×740/800×900 크기 변경을 확인했다. 5176 QA 주소에서는 지도 로딩 오류 안내가 표시되어 등록된 주소에서 재검증했다. 출근역·자체 지하철 오버레이는 없으며 카카오 기본 배경 표기는 유지한다. SDK 중복 로드·키 누락·오류 재시도·시간 초과 회귀 테스트 포함 총 302개 테스트 통과. 실제 Android WebView 검증은 별도다.

## 최초 아파트 오버레이 누락 수정 · 2026-09-21

목록 API에 좌표가 없는데 단지 선택 후에만 좌표를 조회해 최초 지도에 마커가 없던 문제를 수정했다. 탐색 목록의 현재 페이지(최대 50개)에서 미확인 좌표를 순차 조회하고 저장되는 즉시 지도에 반영한다. 이미 확인한 좌표는 재사용한다. 페이지/선택 변경은 이전 요청을 중단하고 같은 컴포넌트 작업을 직렬화한다. 위치가 모호한 단지는 목록에 유지하며 인증/한도/네트워크 오류는 중단한다.

사용자 저장소를 사용하지 않는 격리 화면에서 실제 풍납 대동아파트의 좌표 없는 목록 레코드로 시작해, 선택 없이 기본정보/주소 변환 후 카카오 오버레이가 나타나는 것을 확인했다. 302개 테스트·lint·웹 빌드 통과. 지도 자료의 일괄 준비 완료가 아니라 현재 목록 페이지의 점진적 위치 수집이다.

## 필터·가격 조회 연결 보완 · 2026-09-21

미확인 포함 정책으로 가격/면적 등이 아직 없는 단지가 전체 결과에 남았고, 목록 자동 수집에는 가격 조회가 빠져 있었다. 목록의 단지 기본정보·위치 조회에 구별 12개월 실거래 조회를 연결하고 실행 중 동일 구 응답을 재사용한다. 기본 사실은 거래 조회 실패 시에도 보존한다. 구 전체 기록을 함께 매칭해 중복 소유 거래가 임의로 연결되지 않도록 유지한다.

홈에서 현재 표시 결과를 조건 충족 / 조건 확인 대기 / 조건 밖 보관으로 구분한다. 미확인 포함을 홈에서도 변경 가능하며, 미확인 제외는 미조회 자료도 제외한다는 안내를 제공한다. 기존 후보·방문 기록 보존 정책은 유지한다. 지역·예산·면적·연식·세대수·통근 필터와 API 가격 유입 전후/보관 후보 분류 회귀 테스트 추가.

격리 QA에서 실제 영등포푸르지오를 공공 목록에서 가져와 선택 없이 가격 연결 성공. 같은 실제 자료가 예산 0원에서는 0개, 100억원에서는 1개로 필터링됨을 확인했다. 거래 없음/이름·전체 지번 불일치/중복 매칭 단지는 여전히 가격 미확인이다. 전체 단지 가격을 수집 완료했다는 의미는 아니다. 306개 테스트·lint·웹 빌드 통과.

## 2026-09-21 자동 통근 조회 / API 차단 화면
- 탐색 화면의 단지 선택·첫 50개 제한을 제거하고, 선택한 탐색 지역의 전체 단지를 순차 조회한다. 조회로 목록 순서·필터 결과가 바뀌어도 작업을 재시작하지 않는다.
- 단지별 상세·위치·실거래 확인 후 지정 출근역까지 ODsay 통근시간을 자동 조회한다. 성공·경로 없음은 실행 중 재사용하며 목적지가 바뀌면 다시 조회한다.
- 자동 조회 및 연결 설정의 수동 API 조회 중 native modal dialog로 배경 조작을 차단한다. 진행 안내·중단·이어서 조회를 제공한다. 한도/인증/통신 오류 시 후속 호출을 멈추고 완료 자료를 유지한다.
- 통근은 분 단위 참고 소요시간이며 직선거리나 특정 출근 시각 예측이 아니다. 서울 전체 실 API 완주 및 Android 기기 UI는 이번 검증에 포함하지 않았다.
- 검증: 40개 테스트 파일 / 311개 테스트 통과, ESLint 및 웹 production build 통과. 합성 응답으로 55개 단지 무선택 통근조회, 캐시, 목적지 변경, 경로 없음, 한도, 취소 검증.

## 모바일/UI 검증 통합

기존 수동 QA 문서의 확인 범위를 통합했다. 360×740, 360×480, 375×812, 800×900 브라우저 화면에서 탐색·필터·비교·설정·임장 입력을 표본 확인했다. 별도 저장소에서 합성 사진 첨부, 항목 연결, 초안 복원, 수정·삭제·새로고침 보존과 사진 백업 복원을 확인했다. 사진 백업 형식은 PHOTO_BACKUP.md를 따른다.

UI 정리 당시 375×812/800×900에서 지도·목록 배치와 가로 넘침, 설정 행 편집, 상세→임장, 면적 필터를 확인했다. 해당 격리 주소에서는 카카오 지도 인증이 실패하여 실제 지도 렌더링은 그 UI 검증에 포함하지 않았다. 이후 단계 마커 변경은 lint/빌드 확인만 했으며 실제 지도 시각 검증은 미완료다.

APK 컴파일·설치·서명 업데이트, 실제 카메라·JPEG/HEIC 방향·대용량 사진, 저장 공간 부족, 강제 종료, 폴드 접힘·펼침·회전·키보드·분할 화면은 실기기 확인이 필요하다. 과거 브라우저 QA는 이를 대신하지 않는다. 일회성 QA 화면·샘플 파일은 정리했고 자동 회귀 테스트는 유지한다.
