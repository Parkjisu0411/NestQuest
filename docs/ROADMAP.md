# NestQuest 개발 현황

## 현재 구현

- 서울 일반 아파트의 공공 목록·상세·실거래와 카카오 주소 변환·지도·참고 통근 연동.
- 최초 지역 선택은 자체 지도, 아파트 탐색은 카카오 지도와 단계별 오버레이.
- 가격·면적·연식·세대수·통근 필터와 미확인 포함 선택.
- 관심·방문·최종 후보·제외, 방문 전 비교 및 후보 지정.
- 구조화 임장·선택형 집 내부·사진·메모·장단점·가중평가.
- IndexedDB 저장, 초안, 사진 포함 백업·복원 및 조회 완료 지점 재사용.
- API는 화면을 차단하지 않고 조회한다. 현재 화면/조회 범위를 벗어나면 작업이 중단될 수 있으며 저장된 결과는 재사용한다.
- 모바일 지도 중심, 넓은 화면 지도+목록, 하단 탐색/비교/설정.
- 로컬 키 포함 개인 APK용 Capacitor 구성 및 네이티브 어댑터.

## 남은 검증

1. 최신 단계 마커·묶음 목록의 실제 지도 시각 확인.
2. Android 도구 준비, APK 컴파일·설치 및 동일 서명 업데이트 시 기록 유지.
3. 기기 API 인증·카메라·파일·백업 복원·오프라인·저장 공간 부족 확인.
4. 폴드 접힘/펼침·회전·분할 화면·키보드·뒤로가기 점검.

서울 전체 단지의 정보가 모두 확인되었다는 의미는 아니다. 수도권 확장은 현재 서울 지원 범위와 별도다.

## 수도권 확대 계획 (2026-09-23)

### 1. 서울 누락 원인과 조회 범위부터 검증
- 일반 아파트로 확인되지 않은 원본 단지는 필터 이전에 숨겨진다. 유형 확인과 가격·통근 미확인은 별개다.
- 자동 조회 최대 50개 중 최대 25개를 선택 지역의 미완료 상세·위치에 배정하고 구별로 나눠 처리한다.
- 조회로 화면 결과가 변해도 진행 중인 배치를 취소하지 않는다. 사용자 필터·페이지·선택 변경은 새 범위로 전환한다.
- 데이터 관리의 구별 수집/일반 아파트/유형 미확인/위치 확인 건수로 휴대폰 저장 상태를 진단한다.
- 전체 수집은 데이터 관리의 명시적 전체 자료 준비로 진행한다. 자동 배치 한 번으로 전체 지역이 완성되는 것은 아니다.

### 2. 지역 코드와 수집기를 서울 전용에서 수도권 공통으로 변경
- 서울(11), 인천(28), 경기(41)의 현재 법정동/시군구 코드와 개편 이력을 공식 자료로 확인한다.
- 공공 목록 수집을 시도 인자로 일반화하고, 시/구 계층과 중복 구 이름을 코드로 구별한다.
- 시도별 수집 완료 상태를 저장한다. 서울 자료가 있다는 이유로 경기/인천 신규 수집을 건너뛰지 않게 한다.
- 기존 kapt ID와 임장/관심 기록을 유지하며 지역을 추가한다.
- 완료 기준: 각 시도 페이징·중복·누락 테스트, 기존 서울 데이터와 안전한 병합.

### 3. 주소·가격·지하철 자료의 서울 제한 해제
- 서울만 허용하는 지번 주소 파서를 시도/시/구/읍/면/동/리 주소로 확장한다.
- 이름만 같은 단지가 연결되지 않도록 법정구역 코드와 지번 기반 실거래 매칭을 유지한다.
- 카카오 위치 결과의 허용 범위, 역 선택 자료, 역 ID 검증, 지도 초기 범위의 서울 의존을 함께 점검한다.
- 지도는 기존 카카오 지도를 유지한다. 최초 설정 지도는 수도권 시도 선택 → 시군구 선택으로 구성한다.
- 행정 경계·역 데이터는 출처/기준일/라이선스를 검증한 정적 자료로 갱신한다.
- 완료 기준: 경기 일반시·일반구·읍면리 및 인천 주소 매칭/역 선택/지도 표시 테스트.

### 4. 단계적 지역 도입 및 APK 초기 자료 분할
- 1차 후보: 부천·광명·안양·김포·고양·인천 계양/부평. 여의도 출근 후보지를 먼저 검증한다.
- 2차: 나머지 경기·인천. 지역별 API 실제 응답과 호출 한도를 확인한 뒤 확대한다.
- 초기 자료를 시도/시군구 단위로 나눠 선택 지역부터 불러온다. 전 지역 API를 앱 시작 때 일괄 조회하지 않는다.
- 완료 기준: 재시작 시 캐시 재사용, 지역 추가/해제, 가격·통근 갱신, 폴드 양쪽 화면 및 기존 기록 보존.
- 기존 API의 지역 커버리지·승인·한도는 구현 전 확인한다. 현재 단계에서는 추가 서비스 가입을 요구하지 않는다.

## 수도권 구현 반영 · 2026-09-23
- 서울·경기·인천 현행 시군구 선택, 시도별 단지 수집 및 캐시 분리 구현.
- 시/구 및 읍/면/리 지번, 2026년 개편 코드와 과거 거래 매칭 지원.
- 자체 선택 지도는 공식 2025년 경계에 기반한 시군 묶음/세부 구 선택, 실제 탐색 지도 범위는 수도권 대응.
- 남은 검증: 실제 경기·인천 API 전체 응답과 매칭률, 2026년 구별 최신 경계 교체, 누락된 수도권 역 자료 보강, 모바일 선택 지도 확인.
