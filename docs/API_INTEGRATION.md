# API 연동 구조 · 2026-09-21

실제 인증과 서울 25구 표본을 확인했다. [실행](API_SETUP.md), [검증](LIVE_VALIDATION.md)을 따른다.

- 목록은 서울 전체 페이지 검증 후 반영하고 공급자 ID를 유지한다.
- 기본/상세는 20개 단위 순차 조회. 도로명 실패 시 전체 지번으로 좌표 재확인. 모호한 위치를 추정하지 않는다.
- 구별 12개월 거래는 이름+전체 지번이 맞는 단지에 연결. 중복 식별은 해당 단지 미확인. 전용면적별 취소 제외 중앙값과 이력.
- Kakao는 탐색 지도, 주소 좌표, 통근을 담당. 초기 설정 지역 지도와 출근역 검색은 앱 내 자료.
- 카카오 대중교통는 아파트→출근역 참고 통근. 실패 유형을 구분하며 기기 저장 후 30일 재사용.
- 개발 웹은 허용 공급자만 중계하는 loopback 프록시, APK는 CapacitorHttp.
- 키는 로컬 설정에서 개인 빌드에 포함하며 필수 모바일 입력은 없다. [보안 경계](LOCAL_KEYS.md).
- IndexedDB에 단지·기록·사진 저장. v2 백업에 단지를 포함하며 v1 복원 지원.

네이티브 인증·파일·카메라 동작은 APK 검증 단계다.
