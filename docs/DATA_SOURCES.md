# 데이터 출처 · 2026-09-21

|기능|출처|시점|
|---|---|---|
|단지 목록|공공 공동주택 단지 목록|수집 요청|
|건축/세대/주차|공동주택 기본정보의 기본·상세|상세 수집|
|매매 거래|아파트 매매 실거래가 상세|구별 갱신|
|주소 좌표|Kakao Local REST|위치 확인|
|참고 통근|카카오 대중교통|사용자 요청, 기기 저장 후 30일 재사용|
|경계·역·노선|SGIS·서울시·국가철도공단 공개 파일|개발 시 가공, 앱 내 자료|
|임장·평가·사진|사용자 입력|기기 내 저장|

가격은 호가가 아닌 12개 계약월의 동일 전용면적 유효 거래 중앙값이다. 미매칭은 미확인이다. 역 이후 회사 도보는 통근에 포함하지 않는다.
