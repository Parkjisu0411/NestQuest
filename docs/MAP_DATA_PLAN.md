# 자체 지도 자료와 재생성 · 2026-09-21

초기 지역 선택은 React/SVG 자체 지도, 출근역 검색은 앱에 포함한 자료를 사용한다. 아파트 탐색은 카카오 지도와 오버레이를 사용한다. 자체 경계와 역 검색은 실시간 API 호출이 필요 없으며, 아래는 자료 출처와 재생성 절차다.

## 현재 범위

서울 25구, 역 레코드 783개, 분기 포함 경로 28개. 환승역의 운영기관별 ID가 있어 783은 물리적으로 서로 다른 역 수가 아니다. 1~9호선·공항·신분당·수인분당·경의중앙·경춘·우이신설·신림·김포골드·서울 주변 서해 구간·GTX-A 포함. 수도권의 모든 경계/철도 지원은 아니다.

1호선 운영기관 경계와 경인/경부/광명/서동탄 분기, 2호선 순환/지선, 5호선 마천, 6호선 응암 순환, 7호선 운영기관 경계, 8호선 별내를 대조했다. 원본 좌표가 없는 서울 밖 도라산은 표시하지 않는다. 역명 변경은 별도 대응하며 기존 저장 ID는 유지한다.

자료에 포함된 역 사이 연결은 실제 철도 선형/보행 경로가 아니다. 출근역 검색은 포함된 서울 밖 역도 가능하다. 한강 수계 도형은 현재 범위가 아니다.

## 재생성

원본 폴더에 bnd_sigungu_00_2025_2Q.shp/dbf/prj/shx, 전체 역사 JSON(stations.json), metro-distance.csv를 둔다.

1. npm run map:rail:fetch -- tmp-map
2. npm run map:convert -- tmp-map
3. npm run map:prepare -- tmp-map/normalized.json --check
4. npm run map:prepare -- tmp-map/normalized.json

첫 명령은 공개 철도 CSV를 tmp-map/rail에 받으며 키를 읽지 않는다. 첨부/컬럼/조건 변경 시 검증 실패로 중단한다. 공개 원본 해시와 대응표는 provenance에 기록한다. 갱신 시 개통/노선 순서와 조건을 재확인한다. 원본은 앱에 넣지 않고 정규화 자료와 출처만 포함한다.

현재 공개 파일로 대체했으므로 **추가 KRIC 키 발급은 필요 없다**. 


## 카카오 탐색 지도 전환 · 2026-09-21

아파트 탐색은 카카오 Maps JavaScript SDK와 CustomOverlay를 사용한다. 초기 설정의 서울 구 선택 지도만 자체 SVG로 유지한다. 지도에 출근역·자체 지하철 레이어를 추가하지 않는다. 화면 픽셀 기준 아파트 묶음, 단지 선택과 목록 연동, 필터 반영, ResizeObserver relayout, SDK 오류·시간 초과·재시도를 처리한다. 지도는 인터넷 연결이 필요하며 실패해도 목록/임장 저장은 유지된다.

로컬 NESTQUEST_KAKAO_JAVASCRIPT_KEY를 사용하며 실제 실행 origin을 JavaScript SDK 도메인에 등록한다. 개발/검증용 주소와 APK https://localhost를 각각 등록한다. REST 주소 변환 키는 유지한다. 추가 지도 키는 백업에 넣지 않는다.
